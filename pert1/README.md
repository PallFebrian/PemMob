# Praktikum Pemrograman Mobile - Modul 1

Modul 1 ini berisi latihan dasar Flutter, mulai dari membuat project, mengenal struktur aplikasi Flutter, sampai membuat tampilan sederhana menggunakan beberapa widget.

## Materi yang dipelajari

### 1. Membuat Project Flutter

Mempelajari cara membuat project Flutter baru dan mengenal struktur folder serta file yang digunakan dalam aplikasi Flutter.

### 2. StatelessWidget

`StatelessWidget` digunakan untuk membuat tampilan yang tidak memiliki perubahan data atau kondisi selama aplikasi berjalan.

Contohnya seperti menampilkan teks, icon, atau tampilan sederhana yang tidak membutuhkan perubahan.

### 3. StatefulWidget

`StatefulWidget` digunakan ketika tampilan aplikasi membutuhkan perubahan data atau kondisi.

Pada modul ini digunakan `setState()` untuk mengubah tampilan ketika terjadi perubahan pada data.

### 4. Scaffold dan AppBar

`Scaffold` digunakan sebagai struktur dasar halaman Flutter, seperti tempat untuk `AppBar`, `body`, dan bagian lainnya.

`AppBar` digunakan untuk membuat bagian atas halaman yang biasanya berisi judul aplikasi atau halaman.

### 5. Text

Widget `Text` digunakan untuk menampilkan tulisan pada aplikasi, seperti nama, NIM, judul, atau informasi lainnya.

### 6. Icon

Widget `Icon` digunakan untuk menampilkan berbagai macam icon yang sudah disediakan oleh Flutter.

### 7. Column

`Column` digunakan untuk menyusun beberapa widget secara vertikal dari atas ke bawah.

### 8. setState()

`setState()` digunakan pada `StatefulWidget` untuk memberi tahu Flutter bahwa ada perubahan data sehingga tampilan perlu diperbarui.
